# Security and Privacy

NoteNest encrypts data while it is transmitted between the user's device and NoteNest servers using HTTPS.

Stored note data is encrypted at rest.

NoteNest employees do not routinely read users' private notes.

Users should use a strong and unique password for their NoteNest account.

Users can view active login sessions from Settings under the Security section.

A user can sign out of all other active sessions from the Security settings.
