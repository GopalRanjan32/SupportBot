# Subscription Cancellation

Users can cancel their NoteNest Pro subscription at any time.

To cancel:

1. Open Settings.
2. Select Billing.
3. Click "Manage Subscription".
4. Select "Cancel Subscription".

After cancellation, Pro features remain available until the end of the current billing period.

NoteNest does not immediately delete notes when a subscription is cancelled.

After the billing period ends, the account is moved to the Free Plan.
