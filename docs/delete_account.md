# Deleting a NoteNest Account

Users can permanently delete their NoteNest account.

To request account deletion:

1. Open Settings.
2. Select Account.
3. Click "Delete Account".
4. Confirm the deletion request.

After confirmation, the account enters a 7-day recovery period.

During these 7 days, the user can cancel the deletion request by logging back in.

After the recovery period ends, the account and stored notes are permanently deleted.
