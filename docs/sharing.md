# Sharing Notes

NoteNest users can share individual notes with other people.

To share a note:

1. Open the note.
2. Click "Share".
3. Enter the recipient's email address.
4. Choose Viewer or Editor access.
5. Click "Send Invitation".

Viewers can read the shared note but cannot modify it.

Editors can read and edit the shared note.

Only the note owner can delete the note or change another person's access level.
